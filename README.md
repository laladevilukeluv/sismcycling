# Portfolio Website

## Overview
知り合いに委託されて作ったサイトです。
React / Next.js を用いて、シンプルで見やすい構成を意識して実装しました。

## Demo
https://v0-deploy-to-vercel-rho-six.vercel.app/

## Tech Stack
- TypeScript
- React
- Next.js (App Router)
- Tailwind CSS
- Vercel

## Features
- コンポーネントベースでのUI構築
- Tailwind CSSによるレスポンシブ対応
- Vercelを用いたデプロイ

## Points
- `.tsx` を用いたTypeScript実装
- 再利用性を意識したコンポーネント分割
- UIの可読性・保守性を意識した構成

## Future Improvements
- オンラインから予約できる機能
- アニメーションやインタラクションの改善
- 軽微な不具合の修正
